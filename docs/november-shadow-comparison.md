# 11월 로컬 모델 병행 비교

운영 판단을 바꾸지 않는 읽기 전용 비교다. 운영 분류/의미중복 요청에 기록된 동일 입력을 세 고정 모델 조합에 넣는다. 추가 API 호출, 게시, 발송, 자동 모델 교체는 없다. 기존 GPT/캐시 답변 하나를 공통 참조로 재사용한다. 장학금 별도 게시나 확정 중복처럼 모델 요청을 생략하는 정책 경로는 이 시험의 분모가 아니다.

| 고정 조합 | 분류 학습 | 중복 학습 |
| --- | ---: | ---: |
| baseline-1106 | 5,138건 | 2,769쌍 |
| heldout-1106 | 5,258건 | 2,897쌍 |
| full-corpus-1106 | 6,708건 | 4,906쌍 |

`shadow-models.json`의 시작 시각 이후 관측만 전향 비교에 사용한다. 모델별 파일 SHA256을 매 배치 확인하여 비교 중 학습/교체를 막는다. 기존 실제 운영 학생의 보완학습은 별개이며 고정 baseline 가중치를 바꾸지 않는다.

모델은 정답 열을 읽지 않고 예측을 먼저 저장한다. 비동기 작업이므로 예측 시각이 API 접수 시각보다 늦을 수 있지만 입력으로 정답을 전달하거나 정답을 보고 모델을 바꾸지 않는다. 모델별 예측이 모두 있는 공통 입력만 성적 비교에 사용한다. 실패·미확인·학습/개발 자료 중복을 숨기지 않는다. 신규 공지(중복 입력의 왼쪽)의 원문 URL·본문·숫자 제거 제목 가족의 해시로 노출 자료를 보수적으로 제외한다. 오른쪽 기존 대표글을 알고 있다는 사실만으로 새 공지를 학습 중복으로 제외하지 않는다. 이 검사만으로 모든 의미적 유사 행사까지 분리됐다고 주장하지 않는다.

보고서는 과제별 GPT 일치/불일치, 공통 비교 수, 기존 자료 겹침, 겹침 없는 공통 표본, 오중복 후보/못 거른 중복 후보, 혼동 유형과 추론 시간을 기록한다. GPT 일치는 사람 정답률이 아니며 후보 쌍 오판 수는 실제 첫 공지 누락 수가 아니다. 중요한 불일치는 원문/대표글을 추가 대조한다.

서버 `.runtime/student/shadow-comparisons.sqlite3`와 `shadow-report.json`에 기록한다. 데이터와 가중치는 Git에 넣지 않는다. `together-shadow.timer`는 2분 간격, 작업은 모델 하나씩 순차 로드한다. CPU 20%, 메모리 300MB 한도이며 기존 무료 학습과 같은 lock을 사용해 겹치지 않는다. 이 제한은 비교 작업에만 적용되며 크롤러 처리 제한이 아니다. 11월30일 이후 비교를 종료하고 기록은 보존한다. Work 자동화는 추가하지 않는다.
