# HWP 첨부 내용 대조

동일한 HWP를 다른 버전에서 저장하면서 파일 해시만 바뀐 경우를 대조한다. 본문 전체, 표·스타일·번호 설정, 삽입 자료와 알 수 없는 스트림은 보존하고 저장 커서·미리보기·파일 요약과 검증된 설정 항목의 순서 차이를 구분한다. 실제 글 내용이나 별도 공문이 다르면 제외하지 않는다. 해석할 수 없는 파일은 기존 바이트 해시 비교를 유지한다. 새 파서는 문서 입력 16MiB, 압축 해제 전체 64MiB까지만 검사한다.

본 제품은 한글과컴퓨터의 한글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다. [한컴 공개 파일 형식 5.0](https://cdn.hancom.com/link/docs/%ED%95%9C%EA%B8%80%EB%AC%B8%EC%84%9C%ED%8C%8C%EC%9D%BC%ED%98%95%EC%8B%9D_5.0_revision1.2.pdf), [olefile 읽기 전용 스트림 문서](https://olefile.readthedocs.io/en/latest/Howto.html).
